# Hi, I'm Furkan

### AI-Native Systems Integrator

I'm a prompt engineer who connects things that weren't built to talk to each other and ships them as one product. AI agents write the code. I write the specs, rules and tests that steer them.

### What I build

<table>
  <tr>
    <td width="50%" valign="top">
      <h4>Multi-tenant SaaS</h4>
      Role hierarchies, per-tenant branding, feature flags and fine-grained permissions. One codebase serving many customers.
    </td>
    <td width="50%" valign="top">
      <h4>Integration layers</h4>
      OAuth accounting, payments, SMS, email and cloud storage behind one clean API, with credentials encrypted at rest.
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h4>Data from hostile sources</h4>
      Headless browsers, bot-protected sites and undocumented APIs, turned into structured data that a product can rely on.
    </td>
    <td width="50%" valign="top">
      <h4>AI in the loop</h4>
      LLM features inside products, and agent-driven development from the first spec to the final deploy.
    </td>
  </tr>
</table>

### How I work

Spec first, then house rules in a `CLAUDE.md`, then the agent builds. Nothing ships with a red test, and every integration is checked live against the real system with MCP browser automation.
